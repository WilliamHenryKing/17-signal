All five must appear in the hero and homepage.

## Engineering and delivery

Separate anchors `.repositories/16-common-ground` and `.repositories/17-signal`, checkouts in `experiences/`, branch `work/website`. Vite, React, strict TypeScript, GSAP, Tailwind, Bun, Biome and Lightning CSS with exact existing compatible pins. No WebGL, video dependency, backend, analytics, scroll hijacking or cross-project runtime imports. Original SVG artwork, locally hosted OFL fonts and explicitly licensed, locally compressed Unsplash imagery with provenance.

Use scoped useGSAP, matchMedia and cleanup. Content appears immediately, with no loading gate. The short arrival completes within five seconds; motion can be disabled and the OS preference is respected. Static/prerendered HTML stays readable without JavaScript. Each hero is supplied separately as standalone HTML/CSS/JavaScript in `/hero.html`, plus source and integration instructions. Global styles are kept separate from hero styles. Native navigation, visible focus, keyboard flows, readable contrast and no hover-only content.

Ports: 16 dev 4526 / preview 4626; 17 dev 4527 / preview 4627. Loopback only, strict ports. One heavy job at a time. Initial compressed page target under 650 KB; no autoplay media. Runtime dependencies and assets are independently installed/copied in each project.

## Sequential gates

1. Provision 16 and save its design/profile. Implement the full homepage and standalone hero.
2. Review actual desktop, tablet, phone, narrow-phone and landscape captures; revise observed defects. Exercise navigation, every discipline, editorial dialogs, local brief, motion controls, reduced motion, keyboard and resize. Check no-JS reading, assets, contrast and console. Measure build and transfer sizes.
3. Document findings and limitations, commit 16, publish GitHub and Cloudflare, verify exact source/assets and live HTTP/UI. Only then begin 17 creative production.
4. Repeat the complete process for 17 with a distinct composition and motion language.
5. Update collection inventory, workspace, README, development, STATUS and HANDOFF, and keep release evidence in both public repositories.

Self-review is not client approval. Browser emulation is not a physical phone test. Sampled motion frames are not uninterrupted viewing. Final judgement should be grounded in visible results and working interactions, not a passing build alone.
